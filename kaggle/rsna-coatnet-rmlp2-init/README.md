# Official CoAtNet-RMLP2 ImageNet initialization

The private Kaggle Dataset mirrors only the official timm
`coatnet_rmlp_2_rw_384.sw_in12k_ft_in1k` config and safetensors checkpoint for
offline execution. It contains no RSNA images, labels, or competition-trained
weights. `SOURCE.json` records the upstream URLs, Apache-2.0 license, and hashes.

The 295,695,280-byte weight file is intentionally ignored by Git. The P2 notebook
requires SHA-256 `91570c7af10fea0af03c1b0a49be3e4775596239890eb4193c75129b3045623e`.
